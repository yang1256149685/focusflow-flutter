## 可用介绍

拾序是一款用于整理每日交付事项的原创任务管理作品。支持任务增删改查、项目与状态筛选、截止日期、完成统计、主题切换与本机 JSON 备份。任务保存在本机，保存失败会保留原状态，导入备份前进行完整校验。界面兼顾桌面与窄屏布局，使用虚构示例任务演示完整操作。

## 技术难点与证据

快速操作通过串行写入防止数据覆盖；导入非法枚举、重复 ID 与日期时不破坏原数据。业务和界面测试覆盖持久化、状态变化、异常回滚及真实表单保存。具体通过项与平台见 testing.md。
